# Contributing Guide

Thank you for your interest in RuralVet-LLM.

This is a completed research project documenting Phase 0-2 experiments. While we are not actively seeking contributions for code changes, we welcome bug reports, documentation improvements, and discussions.

## How to Contribute

### Report Issues

If you find a bug or have a question, please open an issue with:
- Clear description of the problem
- Steps to reproduce (if applicable)
- Expected vs actual behavior

### Improve Documentation

Documentation improvements are always welcome:
- Fix typos or clarify confusing sections
- Add examples or explanations
- Improve formatting

### Code Contributions

Code contributions are limited to:
- Bug fixes that don't change experimental results
- Documentation improvements in code comments
- Performance optimizations that preserve accuracy

Do not submit:
- Changes to experimental parameters
- Different model architectures
- Alternative evaluation metrics

## Pull Request Process

1. Fork the repository
2. Create a branch: `git checkout -b fix/issue-name`
3. Make changes and commit: `git commit -m "fix: description"`
4. Push to your fork: `git push origin fix/issue-name`
5. Open a Pull Request with clear description

## Code Style

- Python: Follow PEP 8
- Use descriptive variable names
- Add comments for complex logic
- Keep functions focused and small
